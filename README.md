# NE-CAT beamline guides

Three illustrated, interactive guides to the NE-CAT beamlines (24-ID-C and 24-ID-E) at the Advanced Photon Source.

**Read them here: https://aps-24id.github.io/necat-guides/**

| File | Guide |
| --- | --- |
| `index.html` | Landing page |
| `NE-CAT_1_How_It_Works.html` | How NE-CAT works: from the storage ring to the detector |
| `NE-CAT_2_Beam_Polarization.html` | Why the X-ray beam is polarized |
| `NE-CAT_3_Scatter_and_Fluorescence.html` | Where to put the fluorescence detector |

Each page is a single self-contained HTML file. The pages link to each other by file name, so keep the names unchanged and keep all four in the same folder.

Values that are assumed or calculated, and not taken from a published source, are marked in the settings table of guide 1. Corrections are welcome: please open an issue.
